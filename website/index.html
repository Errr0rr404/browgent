Local-first co-browse runtime · open source

An AI agent inside your real, logged-in browser.

Browgent is not another chat sidebar. It is a desktop runtime where an agent acts on your actual tabs and session — and you are always one click from taking the wheel. Attach Claude Code (MCP) or Playwright (CDP) to the same tabs, behind a policy engine with exportable trajectories.

Not these

BrowserOS is a browser for end-users to automate their own browsing; Browgent is a runtime you attach agents and Playwright to, with a human in the loop. Comet, Dia, and Atlas are the consumer-category reference — polished AI browsers with a closed assistant.

60-second builder path

  1. Install or npm run dev
  2. Status bar: mcp · :17342 (token in userData)
  3. npm run mcp → wire Claude Code
  4. In-app: Run demo or a recipe chip (takeover leads)
  5. Take over on a login wall → Resume → Export trajectory

Who this is for

Beachhead: developers building browser agents that keep failing on real login / SSO / CAPTCHA walls. Browgent gives those agents a local, logged-in session and a human who can step in and hand control back — with policy and an audit trail.

Also useful for HITL automation/ops teams and eval/safety labs that need exportable trajectories.
