# Browgent v0.2.0

First public open-source release.

## Download

- **macOS (Apple Silicon):** [Browgent-mac-arm64.dmg](https://github.com/Errr0rr404/browgent/releases/latest/download/Browgent-mac-arm64.dmg)

First open: right-click → **Open** (unsigned build).

## Highlights

- Local-first multi-tab Chromium with shared human + agent tabs
- Agent tools: navigate, click, type, observe, extract, tabs, …
- Grok tool-calling (`XAI_API_KEY`) or offline heuristic planner
- Act / Research / Watch modes + safety policies
- Trajectory export, voice input, Arc-style sidebar, 10 themes
- MIT licensed

## From source

```bash
git clone https://github.com/Errr0rr404/browgent.git
cd browgent && ./setup.sh && npm run dev
```
