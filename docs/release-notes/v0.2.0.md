# Browgent v0.2.0

First public open-source release.

## Download

- **macOS (Apple Silicon):** [Browgent-mac-arm64.dmg](https://github.com/Errr0rr404/browgent/releases/latest/download/Browgent-mac-arm64.dmg)

First open: right-click → **Open** (unsigned build).

## Highlights

- Current release: **v0.2.0**.
- Local-first multi-tab Chromium with shared human + agent tabs
- Agent tools: navigate, click, type, observe, extract, tabs, …
- Multi-provider OpenAI-compatible brain (Grok default) or offline heuristic planner
- Dual driver: DOM inject + CDP Input; Playwright `connectOverCDP` on localhost (CDP off by default — opt in with `BROWGENT_CDP_PORT`)
- Act / Research / Watch modes + safety policies (`http(s)` and `about:blank` only)
- Trajectory export with secrets redaction, voice input, Arc-style sidebar, 10 themes
- MIT licensed

## From source

```bash
git clone https://github.com/Errr0rr404/browgent.git
cd browgent && ./setup.sh && npm run dev
```
