# Shortcuts

Modifier is **⌘** on macOS, **Ctrl** on Windows/Linux.

These work from chrome **and** while a guest page is focused (the page view is a native Chromium layer, so accelerators are handled in the main process).

| Shortcut | Action |
|----------|--------|
| ⌘/Ctrl+T | New tab |
| ⌘/Ctrl+⇧+T | Reopen last closed tab |
| ⌘/Ctrl+W | Close active tab (or close History/Settings overlay) |
| ⌘/Ctrl+L | Focus address bar |
| ⌘/Ctrl+R | Reload active tab (toolbar button stops while loading) |
| ⌘/Ctrl+F | Find in page |
| ⌘/Ctrl+Y | History |
| ⌘/Ctrl+⇧+J | Downloads panel |
| ⌘/Ctrl+⇧+U | Summarize page (research mode) |
| ⌘/Ctrl+P | Print page |
| ⌘/Ctrl++ or = | Zoom in |
| ⌘/Ctrl+- | Zoom out |
| ⌘/Ctrl+0 | Reset zoom |
| ⌘/Ctrl+J | Toggle agent panel |
| ⌘/Ctrl+, | Settings |
| ⌘/Ctrl+⇧+S | Toggle sidebar |
| ⌘/Ctrl+D | Pin / unpin favorite (Arc-style) |
| ⌘/Ctrl+1 … 8 | Switch to tab N |
| ⌘/Ctrl+9 | Last tab |
| ⌘/Ctrl+[ | Back |
| ⌘/Ctrl+] | Forward |
| Escape | Close find / downloads / history / settings; blur address bar; or **Stop** agent when busy |
| Middle-click tab | Close tab |
| Right-click tab | Duplicate, close others, copy URL, reopen |
| Right-click page | Back / forward / reload, open link in new tab, copy, inspect |

## Omnibox chrome URLs

| Input | Opens |
|-------|--------|
| `browgent://settings` / `settings` | Settings |
| `browgent://history` / `history` | History |
| `browgent://downloads` / `downloads` | Downloads panel |

## Agent panel

| Input | Action |
|-------|--------|
| Enter | Send (Shift+Enter for newline) |
| Mic | Toggle voice input |
| Allow / Deny | Policy confirmation |
